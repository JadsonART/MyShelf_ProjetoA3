meu-projeto/
│
├── .github/                # Configurações do GitHub
│   ├── workflows/          # CI/CD (Actions)
│   │   └── ci.yml
│
├── docs/                   # Documentação
│   └── guia.md
│
├── src/                    # Código-fonte principal
│   ├── __init__.py         # (se for Python)
│   └── main.py             # arquivo principal
│
├── tests/                  # Testes automatizados
│   └── test_main.py
│
├── .gitignore              # Arquivos a serem ignorados pelo Git
├── LICENSE                 # Licença do projeto
├── README.md               # Documentação inicial
├── requirements.txt        # Dependências (Python) ou package.json (Node)
└── setup.py / pyproject.toml  # Configuração de instalação (se Python)


.github/workflows/ → automações (CI/CD, testes, deploy).

docs/ → tutoriais, guias e anotações.

src/ → código do projeto.

tests/ → scripts de teste.

.gitignore → evita subir arquivos desnecessários (ex: cache, credenciais).

README.md → explicação do projeto (objetivo, como rodar, exemplos).

LICENSE → define se outras pessoas podem usar/modificar seu código.

requirements.txt → lista bibliotecas necessárias.

setup.py / pyproject.toml → caso queira distribuir como pacote.
